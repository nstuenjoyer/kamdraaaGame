# Game Setting & Tone: KamdraaaGame

Always adhere to the game's core setting, mood, and mechanical rules when generating scripts, dialogues, shaders, and scenes:

## 1. Setting & Genre
- **Genre**: Neo-noir comedic thriller / stealth-action detective.
- **Protagonist**: Dasha — suffering from severe hangover, paranoia, and memory loss after a chaotic night out.
- **Tone**: Dark comedy meets intense thriller. Ordinary mundane hangover details mixed with paranoid spy/crime syndicate tropes.

## 2. Core Mechanics to Support
1. **Dynamic Camera Transition (Isometric ⇄ Top-Down Hotline Miami)**:
   - Exploration is 2D isometric.
   - Action / Panic / Phone calls switch dynamically to strict Top-Down (90° overhead) view with synthwave music and neon shader effects.
2. **Reality Distortion / Paranoia System**:
   - Everyday items appear terrifying through Dasha's hangover perception (lipstick = blood, animators = hitmen, birthday cake = C4 bomb).
   - Systems should allow visual/textual "paranoia toggles" or stress levels.
3. **Improvised Stealth & Combat**:
   - Dasha fights with improvised domestic objects (vases, pepper spray, pushing coat racks, blinding with flashlights) and quick contextual interactions (QTE).
4. **Investigation Diary / Evidence Board**:
   - Inspectable full-screen documents (receipts, notes, photos) linked together on a corkboard in the player's inventory/mind.
