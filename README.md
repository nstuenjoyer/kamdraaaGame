# Kamdraaa

Психологический нуарный детективный триллер на **Godot 4.7.2** для Windows. Даша просыпается в тёмной квартире и пытается разобраться в случившемся: исследует комнаты, сопоставляет записи и ищет выход, пока тревога меняет восприятие окружающего.

В проекте реализована первая глава — **«Тёмная квартира»**. Новая игра запускает квартиру из десяти зон с исследованием, предметными головоломками и финальной встречей. Продолжение за входной дверью пока не реализовано.

## Что уже работает

- Причинная цепочка расследования: осмотры, документы, запертый кабинет, кодовая картотека и механический засов. Часть предметов можно найти заранее; электричество, зарядка телефона и подготовка защиты остаются необязательными ветками.
- Тревога, искажения и ограниченный запас таблеток. Первую дозу игрок принимает вручную через сумку; накопленная тревога сама не снижается. Свет останавливает страх темноты.
- Фонарик в руке: доставание из кармана, наведение и убирание согласованы с ходьбой, бегом и приседанием. Луч начинается у линзы и учитывает стены и мебель.
- Встреча с противником: зрение и слух, укрытия, отвлечение, ослепление, подручные предметы, QTE и три исхода с контрольной точкой.
- Сумка с иллюстрированной сеткой предметов, бумажный дневник задач и записей, документы с изменением размера текста, план квартиры и контекстные подсказки.
- Главное меню с иллюстрацией и симуляцией дождя на стекле; настройки звука, экрана и управления, клавиатурная навигация и слотовые сохранения.
- Покадровая анимация Даши, пространственная атмосфера квартиры, записанные дождь и пульс, синтезированные звуки взаимодействий и шагов.

Художественное оформление и баланс продолжают дорабатываться. Автоматические проверки не заменяют авторский плейтест и не подтверждают длительность первого прохождения. Ранние концепции из [дизайн-документа](docs/GDD.md) могут отличаться от реализованной главы.

## Запуск из исходников

1. Установите Godot **4.7.2** для Windows и клонируйте репозиторий.
2. Импортируйте `project.godot` в редактор и дождитесь импорта ресурсов.
3. Запустите весь проект клавишей **F5**, затем выберите «Новая игра».

Либо запустите проект из PowerShell, указав путь к движку:

```powershell
& 'C:\path\to\Godot_v4.7.2-stable_win64.exe' --path .
```

Стартовая сцена — `scenes/main_menu.tscn`, первая глава — `scenes/chapter_1/apartment.tscn`. Сцена `scenes/main.tscn` сохранена как исторический регрессионный стенд.

## Управление

Привязки ниже указаны по умолчанию. Переназначенные клавиши отображаются в игровом интерфейсе.

| Действие | Клавиши |
|---|---|
| Движение | WASD / стрелки |
| Бег | Ctrl |
| Присед / красться | Shift |
| Взаимодействие | E / Пробел / Enter |
| Фонарик | F / правая кнопка мыши |
| Сумка | I |
| Дневник | J / Tab |
| План квартиры | M |
| Пауза / закрытие окна | Escape / P |
| Быстрое сохранение | F5 / K / F6 |
| Быстрая загрузка | F9 / L / F8 |
| Полный экран | F11 / Alt + Enter |

Во время модальных действий движение блокируется. В открытом окне Tab переключает фокус, а I/J/M позволяют напрямую перейти между сумкой, дневником и планом. Действия во время встречи показаны в контекстном интерфейсе и справке «Как играть». При запуске внутри редактора учитывайте его собственные сочетания клавиш.

## Сохранения

Слоты первой главы находятся в `user://saves/chapter_1/`. Текущая схема данных — версия 3, планировка — ревизия 2. Старые сохранения сохраняются на диске и отображаются несовместимыми, если не подходят текущей главе.

Сохранение недоступно во время вступления, документа, выбора, QTE и из укрытия. Итог главы записывается также в `user://chapter_1_result.json`; перенос этого результата в продолжение пока не реализован.

## Проверки

Запускайте из корня проекта. PowerShell-обёртки изолируют тестовые настройки и сохранения от пользовательских данных. Путь к Godot можно передать через `-GodotExe`.

```powershell
# Механики главы и причинный маршрут
./tools/run_chapter_checks.ps1 -GodotExe 'C:\path\to\Godot_v4.7.2-stable_win64.exe'
./tools/run_chapter_checks.ps1 -Route -GodotExe 'C:\path\to\Godot_v4.7.2-stable_win64.exe'

# Интерфейс, главное меню, компоновка и анимации
./tools/run_ui_checks.ps1
./tools/run_frontend_checks.ps1
./tools/run_presentation_checks.ps1

# Удержание фонарика, движение руки и свет на стенах
./tools/run_held_flashlight_checks.ps1
./tools/run_arm_motion_checks.ps1
./tools/run_hand_wall_checks.ps1
```

У обёрток есть собственные параметры; проверьте их перед запуском. Проверки графики используют реальный рендерер. Поддерживаемый параметр `-PackedGame` запускает проверки существующей экспортированной EXE/PCK: после правки исходников экспорт необходимо обновить отдельно. Последние результаты и ограничения приведены в отчётах `AI/review/`.

## Сборка для Windows

Нужны Godot с экспортными шаблонами и Inno Setup. Из корня проекта:

```powershell
./build_installer.ps1 -GodotExe 'C:\path\to\Godot_v4.7.2-stable_win64.exe' -IsccExe 'C:\path\to\ISCC.exe'
```

Скрипт создаёт EXE/PCK в `build/dist/`, установщик `Kamdraaa_Setup_v0.2.0.exe` и portable-архив `Kamdraaa_v0.2.0_Portable.zip` в `installer/`. Каталоги сборок исключены из Git; наличие исходников в репозитории не означает публикацию готового дистрибутива.
