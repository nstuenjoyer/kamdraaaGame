# KamdraaaGame

2D изометрическая игра на **Godot 4**.

## 📁 Структура проекта

```
kamdraaaGame/
├── scenes/               # Сцены игры
│   └── main.tscn         # Главная изометрическая сцена (greybox)
├── scripts/              # Исходный код скриптов (GDScript)
│   ├── main.gd           # Точка входа в сцену
│   ├── player.gd         # Управление перемещением Даши (WASD / стрелки)
│   ├── quest_item.gd     # Квестовый телефон и диалог
│   └── door.gd           # Логика двери и отпирания прохода
├── assets/               # Ресурсы игры
│   ├── sprites/          # Папка для ваших спрайтов и текстур
│   ├── audio/            # Папка для звуковых эффектов и музыки
│   └── icon.svg          # Иконка проекта
├── project.godot         # Конфигурация Godot Engine
├── .gitignore            # Исключения кэша движка (.godot/)
└── README.md
```

## 🎮 Управление и механики

- **WASD / Стрелки**: Плавное 8-направленное изометрическое перемещение Даши.
- **E**: Взаимодействие с телефоном.
- **Сюжетный триггер**: Подойдите к телефону и нажмите **E**, чтобы ответить на звонок. После диалога дверь разблокируется, открывая проход.

## 🛠️ Запуск проекта

1. Установите **Godot 4.x**.
2. Откройте проект через Godot (`Import` -> выберите папку проекта `kamdraaa-game`).
3. Нажмите **F5** (Run Project).
