# Покадровая анимация Даши — 1 ноября 2026

**Актуальная переработка:** [REDRAW_AND_RECORDED_AUDIO.md](REDRAW_AND_RECORDED_AUDIO.md). Пропорции перерисованы по исходной Даше, сумка возвращена, добавлено дыхание и проверка всех переходов. Ниже описан предыдущий проход как история; отдельный неподходящий crouch-idle лист теперь не используется.

Деформация одного изображения заменена атласом из 64 отдельно нарисованных поз. `DashaSprite` остаётся Sprite2D, но показывает ячейку атласа, без шейдера походки, наклона целого спрайта и сжатия тела.

`scripts/dasha_animation.gd` управляет состояниями `idle`, `walk`, `run`, `crouch_enter`, `crouch_idle`, `crouch_walk`, `crouch_exit`. Приседание и подъём занимают 0,3 с; удержание Shift сохраняет низкую стойку при остановке. Есть ракурсы спереди и сзади с горизонтальным отражением. Это четыре направления на основе двух нарисованных ракурсов, не восемь независимых углов.

Цикл связан с фактически пройденным расстоянием: 164/220/100 единиц на полный цикл ходьбы/бега/крадущейся ходьбы. При упоре в препятствие фаза не продвигается. Звук шага использует половину соответствующей длины цикла. Ноги всех поз привязаны к общей опорной линии; для фаз полёта бега есть явный подъём на 7 пикселей атласа.

Размер персонажа в существующих сценах сохранён по высоте исходного спрайта. Ключи управления, физика CharacterBody2D, камера, освещение персонажа и узел `DashaSprite` сохранены. Меняются только рисунок и выбор позы; дополнительного изменения коллизий для приседа нет.

Ассеты, исходные генерации, точные промпты и таблица регистрации: `assets/sprites/dasha_animation/README.md`. Для создания использован встроенный imagegen; рабочий атлас находится в проекте. Полный костюм и цвет волос сохранены; сумка убрана с рисунка, чтобы не блокировать движение рук. Предметы инвентаря этим не изменяются.
