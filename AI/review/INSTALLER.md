# Проверка установщика и деинсталлятора

Проверен реальный `installer/Kamdraaa_Setup_v0.2.0.exe` в текущей Windows-среде. Установка шла в отдельную папку проекта с пробелами и кириллицей, без прав администратора. Перед запуском проверяется отсутствие существующей регистрации приложения, чтобы не затронуть установленную пользователем копию.

## Изменения

Стандартный деинсталлятор Inno Setup уже был включён по умолчанию. Теперь `Uninstallable=yes` и `CreateUninstallRegKey=yes` заданы явно, добавлен локализованный ярлык **«Удалить Kamdraaa» в папке игры**. Ярлык удаления в меню «Пуск» и запись в списке приложений Windows также создаются. Исполняемый файл удаления — `unins000.exe`, служебный журнал — `unins000.dat`; отдельно скачивать их не нужно.

Файлы поставки перечислены явно: EXE, PCK и необязательная иконка. Случайные журналы и остатки сборки из `build/dist` не попадут в установку через рекурсивную маску.

Справка производителя: [Uninstallable](https://jrsoftware.org/ishelp/topic_setup_uninstallable.htm), [CreateUninstallRegKey](https://jrsoftware.org/ishelp/topic_setup_createuninstallregkey.htm). Удаление реализовано стандартным механизмом Inno Setup, без самодельного рекурсивного удаления папки.

## Результат

28 проверок прошли:

- установка с кодом возврата 0;
- EXE/PCK установлены и совпадают по SHA-256 с исходной поставкой;
- деинсталлятор, журнал и ярлык «Удалить Kamdraaa» существуют;
- ярлык указывает на созданный деинсталлятор;
- меню «Пуск» содержит запуск игры и удаление;
- запись Windows указывает на тестовую установку;
- повторная установка сохраняет пользовательский файл и не создаёт второй деинсталлятор;
- установленная игра запускается с обычным графическим драйвером и закрывается без ошибок ресурсов/скриптов;
- штатное удаление возвращает 0, убирает игру, собственные ярлыки, журнал и запись Windows;
- сохранения вне каталога игры и не принадлежащий установщику файл внутри него сохраняются.

Отчёт: `.godot/installer-check-392cfb4061d342c397a25bb09756bbfa/report.txt`. Рядом лежат журналы установки, повторной установки, запуска и удаления. Тестовая копия удалена штатным деинсталлятором; исходные файлы сборки сохранены.

Повтор: `tools/check_installer.ps1`. Скрипт откажется использовать AppId уже существующей установки; для такого случая можно собрать тот же сценарий с отдельным `MyAppId` и передать его в тест. Продуктовый AppId не изменён.

Тест выполнен в автоматическом режиме установки; ручное прохождение страниц мастера и проверка на других версиях Windows этим прогоном не подтверждаются.
