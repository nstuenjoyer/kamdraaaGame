# First PSX bedroom furniture pass

Generated by `tools/art/build_apartment_bedroom_kit.py` in isolated Blender 5.2.3.
`source/bedroom_kit.blend` is the packed source, excluded from Godot import.
`bedroom_kit.glb` contains Bed, Nightstand, Lamp and Chest at local origins.
Dimensions are metres, exported Y up. Each piece is instantiated by the 3D world;
the Godot wrapper retains collision geometry and interactive IDs independently.

The kit has chamfered furniture, a triangulated folded cover, octagonal lamp and
two packed 128×128 texture sources. Godot substitutes the common PSX material
palette on import. The mirror is currently a tinted surface, not a reflection.

This is a first art pass awaiting visual assessment. It does not establish final
quality for the rest of the apartment. No character geometry was changed.
