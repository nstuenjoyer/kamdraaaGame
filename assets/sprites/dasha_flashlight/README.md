# Dasha flashlight arm parts

Created with built-in imagegen on 1 November 2026. The original `../dasha.png` and current `../dasha_animation/neutral_reference.png` were supplied as identity/style references. No existing character image was overwritten. No external paid API or third-party artwork was used.

The source is a genuinely transparent RGBA image, **1774×887**, containing four columns and two views. Final cutouts are generated by `repack.py`: alpha cleanup below16, cropping, uniform nearest-neighbour resampling, and pivot registration only. The script does not invent articulated poses or warp the body.

## Runtime parts

`front_*` and `back_*` variants:

- `upper_arm.png`:42×33, dark-purple coat sleeve, shoulder→elbow.
- `forearm.png`:36×20 front /36×18 back, elbow→wrist.
- `hand.png`:13×12, pale gripping fist. The additional sleeve in source column3 is cropped away.
- `flashlight.png`:28×12 front /28×11 back, black metal barrel, silver lens on the left, no baked beam.

Exact pivots and source rectangles are in `parts.json`. Coordinates are in the same scale as the200px-tall Dasha atlas: multiply by the existing character scale during integration. The upper arm is diagonally posed; calculate its native shoulder→elbow angle and subtract it from the desired bone angle. All parts extend from the proximal joint on the right to the distal joint on the left. The flashlight's grip and muzzle are explicitly registered.

`parts_preview.png` is an opaque QA contact sheet, not a runtime asset. Exclude `source.png`, `parts_preview.png` and `repack.py` from the game export if distributing only runtime resources. The root implementation owns draw/stow timing, old-hand occlusion, hand socket and light origin; these parts do not modify existing locomotion proportions.
