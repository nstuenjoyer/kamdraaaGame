Способ: встроенный `image_gen.imagegen`, без CLI и сторонних изображений. Файлы скопированы в проект; исходные PNG не перезаписывались и альфа мебели сохранена. Изометрия, размеры и порядок перекрытия настраиваются движком.

## Промпт паркета

Use case: stylized-concept. Asset type: seamless repeating diffuse floor texture for an isometric 2D psychological noir game. Create one square 1024x1024 orthographic perfectly TOP DOWN material swatch of old warm smoked oak parquet in a modest late Soviet apartment. Narrow long wooden slats with staggered joints, subdued desaturated dark umber and grey brown palette, fine visible grain, occasional scratches, worn varnish, subtle dust in joints. Handmade painterly game environment texture, medium realistic detail, no perspective, no room, no furniture, no objects, no border, no text. Uniform neutral diffuse lighting across whole tile, no cast shadows, no baked directional spotlight. Edges must tile seamlessly, wood boards parallel to vertical image axis. Restrained noir color palette, not saturated orange and not glossy new floor.
