# Короткое интро и свободный проход из спальни

Начало содержит отдельную заставку «АКТ I / ТЁМНАЯ КВАРТИРА»: крупный текст 42 px по центру тёмного экрана, 4,5 секунды полного показа плюс плавное появление/исчезновение. После заставки начинается постановка: окно с дождём, погасший телефон, возврат камеры к просыпающейся Даше. Каждая подпись показывается 4,5–5 секунд и не накладывается на название акта. Далее следуют реплики и первое видение; задача с таблетками появляется по завершении сцены.

Невидимая физическая преграда спальни удалена. До таблетки доступны перемещение по квартире, осмотры и подбор предметов. Обязательная первая доза сохраняется перед попыткой выхода из квартиры: в этом случае Даша явно объясняет, что не может сосредоточиться на замке и должна сначала справиться с приступом. Внутренние двери этим условием не перекрываются.

Регрессия проверяет настоящее перемещение из спальни в прихожую до таблетки и получение предмета при незавершённом обучении. Сюжетный маршрут проверяется отдельным стендом `-Route`. Кадр постановки: `docs/review/images/chapter_1/00-opening.png`.
