Изменения в рабочей копии поверх e5a5f551fcf1cd1b9675e7091ed6d4a802e970a7. Первоначальное ревью сохранено в FINDINGS.md. Кэш обновлён по фактическим SHA-256 исходников; это не новый Git-коммит.

## Исправления R1–R9

- R1: при запуске новой комнаты без pending save сбрасываются улики и выводы.
- R2: таблетки сохраняются как скрытый/неактивный узел, отдельно от количества в инвентаре. Сохраняются picked_up и состояние фонарика; при загрузке восстанавливаются локальные inspected-флаги. Старые сохранения определяют подбор по наличию pills в inventory; если таблетки уже полностью израсходованы в старом формате, точно восстановить факт подбора невозможно.
- R3: сохранение во время активного диалога отклоняется с уведомлением и сигналом false. Завершение звонка открывает дверь и создаёт autosave. Старое v1-состояние answered=true/door=false мигрирует к повторяемому звонку.
- R4: перед загрузкой настроек полностью восстанавливается исходный InputMap; reset возвращает все вторичные клавиши и события мыши. После этого применяются только сохранённые пользовательские действия.
- R5: remove_item отвергает нулевое/отрицательное количество.
- R6: загрузка clues всегда начинает с чистого состояния, в том числе для старого/пустого раздела.
- R7: отмена диалога испускает отдельный dialogue_cancelled; обработчики отключаются и снимают блокировку управления, не выдавая улику и не открывая дверь.
- R8: удалены жёсткие альтернативы действий; история, фонарик, взаимодействия и движение используют InputMap. Документированные мышь/инвентарь зарегистрированы как действия. Подсказки взаимодействий и фонарика берут текущую клавишу. Несколько информационных текстов в сценах/журнале ещё содержат обозначения клавиш по умолчанию; это не дополнительные активные привязки.
- R9: Windows-скрипты вычисляют корень по собственному пути; GodotExe/IsccExe задаются аргументами, переменными GODOT_EXE/ISCC_EXE или PATH. BAT делегирует PowerShell и передаёт код возврата. Inno использует относительные пути, иконка установки условная, ярлыки используют EXE. Windows-проверка остаётся обязательной перед выпуском.

Дополнительно: убрано автоматическое создание demo saves; заморожен стресс при паузе; убрано повторное облегчение на выходе из DarkZone. Запись слота идёт через .tmp + flush + rename. Добавлены проверки версии, вложенных разделов, типов инвентаря и конечности чисел позиции. Это не полная защита от любых вручную сконструированных данных; значения должны дополнительно валидироваться по правилам конкретных будущих механик.

## Изометрические стены и свет

Две задние стены имели теневые контуры на верхнем крае рисунка (смещение вверх на 140 пикселей от физического основания). Контуры NW/NE теперь совпадают с основаниями коллизий, как у остальных стен. Это сознательная модель плоского 2D-света: тени используют план помещения, а видимые грани нарисованы выше основания.

Room1CeilingLight и оконные источники больше не добавляют цвет в затенённые области; shadow_color стал прозрачным чёрным. Для локальных ламп и индикатора двери включены тени, чтобы радиальные текстуры не освещали помещение через стены. Открытая дверь отключает коллизию и свой occluder, закрытая возвращает оба. Полупрозрачные передние грани сохраняют существующий дизайн.

Проверено программно: триангуляция всех 10 коллизионных полигонов и 7 передних граней, совпадение всех 10 wall occluder с коллизиями, луч физики через NW-стену, блокировка/свободный проход двери и отключение её тени. Проверки не заменяют прохождение всех маршрутов персонажем.

Проверено визуально на Mesa llvmpipe/OpenGL Compatibility: помещение освещено; закрытая дверь отделяет тёмный коридор, открытие пропускает свет через проём; тёмная комната остаётся тёмной без фонарика; луч фонарика освещает пол и ограничивается стенами. Зафиксированы обзорные кадры:

## Результаты и повторение

Godot 4.7.2.stable.official.ed1daf0bf, Linux x86_64. Импорт редактором прошёл; в итоговом регрессионном запуске `REGRESSION_RESULT checks=53 failures=0`. Новые проверки включают переход из меню, сохранение/загрузку до/после подбора, завершённый звонок, отмену осмотра, клавиши, повреждённые разделы и геометрию. Exit 0 теперь означает успех проверок, а не наличие старых дефектов.

```bash
source /workspace/.tools/kamdraaa/activate.sh
cd /workspace/kamdraaaGame
XDG_DATA_HOME=$(mktemp -d) godot --headless --path . --script res://docs/review/reproduce.gd
python3 tools/review_cache.py
```

Для повторения кадров требуется работающий X-сервер. В этой сессии использовался Xorg dummy :99 с разрешением 1280×720; сам сервер и процессы не сохраняются в snapshot. `DISPLAY=:99 LIBGL_ALWAYS_SOFTWARE=1 godot --path . --rendering-method gl_compatibility --audio-driver Dummy --resolution 1280x720 --script res://docs/review/capture.gd` сохраняет PNG в /tmp. Скрипт меняет только тестовую сцену/камеру, не исходный дизайн камеры.

Остаётся предупреждение ObjectDB на завершении. Verbose показал AudioStreamWAV/AudioStreamPlaybackWAV; остановка и снятие stream с плееров при _exit_tree не устранили предупреждение. Не считать утечку исправленной. Дублирование UI и потенциальная стоимость шейдера остаются техническим долгом; без измерений массовый рефакторинг и снижение качества графики не выполнялись.
